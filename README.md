# Orquestração Enterprise de RPA

Código base em Selenium para o treinamento [_Orquestração Scripts Python com BotCity_](https://treinamentorpa.botcity.dev/labs/custom/) com Orquestrador BotCity.

---

## Módulos:
- Introdução e requisitos minimos para orquestração de scripts python
- Visão geral do projeto
- Como integrar com o Orquestrador BotCity
- Funcionalidades do BotCity SDK
- Exercícios extras para praticar

---
## Pré-requisitos:
- Noções básicas em lógica de programação;
- Recomendamos que você utilize um computador que seu usuário tenha permissão para executar scripts, alterar permissionamento etc;
- Ambiente configurado ([orientações no link](https://treinamentorpa.botcity.dev/labs/automacoes/checklist/)).
